# Contributing to DeepThroat CLI

Use Bun 1.4.4. Install dependencies with `bun install`, then run `bun run verify`. Configuration schemas and client contracts must be regenerated when their sources change.

Open pull requests against `deepthroat`. Include the problem, behavior change, and verification performed. Keep inference restricted to DeepThroat website accounts and preserve MCP tool integrations. Never commit credentials or private backend files.
