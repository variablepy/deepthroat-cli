DeepThroat CLI brings an account-powered coding agent to your terminal.

- Sign in with your DeepThroat website account and choose an existing account key.
- Use the account model catalog, Build and Plan agents, tools, permissions, MCP, language servers, and skills.
- Run the standalone `deepthroat` executable without installing Node.js or Bun.
- Install with the versioned PowerShell script; downloads are checked against SHA256SUMS.
- External inference providers, custom inference endpoints, and manual provider keys are disabled.

Windows x64 is the first packaged release. The source retains cross-platform build targets. Desktop bundling is released through the separate desktop installer.
